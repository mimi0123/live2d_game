# Live2D 桌宠「部位点击台词」系统说明

点击模型的不同大部位（头/胸/手/腿/衣服…）会触发该部位的台词，逐句顺序播放（打字机效果，点一下跳下一句），可切换随机语序。全部配置都是 JSON，方便随时导入文本和语音。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| 鼠标左键 | 点击模型部位 → 播放该部位台词；播放中再点 → 下一句 |
| 鼠标右键 | 抚摸（爱心粒子） |
| `1` `2` `3` `4` `5` | 直接测试 头/胸/手/腿/衣服 的台词 |
| `空格`/`回车`/`J` | 台词跳到下一句 |
| `F3` | 显示/隐藏调试面板（含台词编辑器） |
| `F4` | 显示/隐藏区域矩形（彩色框，用于微调区域位置） |

## 数据文件（全部可手改，改完重启或点编辑器自动生效）

### 1. `data/regions.json` —— 区域定义

```json
{
  "model": "MO",
  "random_order": false,
  "regions": {
    "头":   { "rects": [[-800, -4000, 1600, 1500]] },
    "胸":   { "rects": [[-1000, -2500, 2000, 1400]] },
    "手":   { "rects": [[-2000, -2600, 950, 1800], [1050, -2600, 950, 1800]] },
    "腿":   { "rects": [[-750, 400, 1500, 2200]] },
    "衣服": { "rects": [[-1150, -1100, 2300, 1600]] }
  }
}
```

- 每个区域可含**多个矩形**（如左右手）。
- 矩形格式 `[x, y, w, h]`，坐标是**以模型中心为原点**的画布像素坐标（按 F4 可看到矩形叠在模型上，直接照着调）。
- `random_order: true` → 该部位台词随机顺序播放。
- 想加新部位（如「脚」「尾巴」）→ 加一个键 + 矩形即可，再在 dialogue.json 加同名台词。

### 2. `data/dialogue.json` —— 台词数据（键 = 区域名）

```json
{
  "speaker": "MO",
  "default": [ {"name": "MO", "text": "嗯？你是在叫我吗～", "expr": "", "voice": ""} ],
  "头": [
    {"name": "MO", "text": "头1：别乱摸头啦～", "expr": "", "voice": ""},
    {"name": "MO", "text": "头2：头发会被你弄乱的！", "expr": "", "voice": "res://audio/head2.ogg"},
    {"name": "MO", "text": "头3：乖，就让你摸一下下～", "expr": "", "voice": ""}
  ]
}
```

- 每句：`name`（说话人）、`text`（台词）、`expr`（表情，Doro 用）、`voice`（语音路径，留空则无语音）。
- **台词可无限添加**，播放时按数组顺序逐句来（说完一句点一下才下一句）。
- 语音文件放 `audio/` 目录（支持 .ogg/.wav）。

## 调试面板「台词编辑」用法（F3 打开）

1. 点部位按钮（头/胸/手/腿/衣服）选择要给哪个部位加台词。
2. 上方列表显示该部位现有台词（带「删」按钮）。
3. 下方输入框填文本（可选填语音路径），点「添加」→ 自动写入 dialogue.json 并热重载，立即可点模型测试。
4. 「随机语序」开关 → 写入 regions.json 的 random_order。

## 相关脚本

- `scripts/gd/region/region_detector.gd`（autoload RegionDetector）：点击检测 + 区域判断 + F4 开关。
- `scripts/gd/region/region_overlay.gd`：区域矩形可视化。
- `scripts/gd/dialogue/dialogue_manager.gd`（autoload Dialogue）：台词播放/打字机/语音/随机。
- `scripts/gd/debug/debug_panel.gd`（autoload DebugPanel）：调试面板 + 台词编辑器。

## 换模型

调试面板「模型」栏可切换 Doro / MO / 欧珀海妖。注意：区域矩形是**按模型坐标**配置的，换模型后需按 F4 看矩形是否还对得上，对不上就在 regions.json 里调。
