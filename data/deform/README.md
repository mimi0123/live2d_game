# 形变贴图（自定义挤压/拉伸形状）

把这个目录里的 PNG 作为「形变贴图」，用来自定义触碰/挤压/拉伸的形状。

## 格式（RGBA 位移贴图）

- 尺寸：推荐 256x256（任意正方形均可）。
- **R 通道** = X 方向位移（0.5 = 无位移，0/1 = 向左右最大）。
- **G 通道** = Y 方向位移（0.5 = 无位移，0/1 = 向上下最大）。
- **B 通道** = 未用（可当深度/占位）。
- 原理：鼠标按住进入该区域时，shader 在触摸点附近以这张图为中心采样，按 RG 位移量把像素往相应方向扭。

## 已有示例

- `dent.png`：向中心凹陷（按压下沉）。
- `bulge.png`：向四周凸起（鼓起）。
- `squeeze_x.png`：横向挤压（左右往中间收）。
- `stretch_y.png`：纵向拉伸（上下往两边撑）。

## 怎么自己画

用 Photoshop / Krita 画：
1. 新画布 256x256，填充 50% 灰（R=G=128，即无位移）。
2. 用黑/白刷子画位移方向：越偏向某处位移越大，灰度代表方向（R 左黑右白、G 上黑下白）。
3. 存成 PNG 放进本目录，游戏里「贴图形变」→「下一个」即可循环选到。

## 注意事项

- 「贴图形变」开关、以及「强度」「半径」滑块控制贴图变形的幅度与范围。
- 左键=凹陷变暗、右键=凹陷提亮（方向/明暗由左右键决定，贴图只管"形状"）。
